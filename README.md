La idea de esta planilla es lograr un mayor control colaborativo sin terminar de romper todo el esquema sobre el que se organiza la carga de los articulos y el regitro de documentos (ordenes de compra y remitos de llegada)
Cuenta con tipos de usuario con mas o menos privilegios de control.
La mayoría de las funciones están tomadas del excel para poder hacerlo lo mas intuitivo posible.
La mayoría de errores son de fácil reparación por el stack simple de lenguajes que tiene por detrás, no hay frameworks complejos o una estructura inentendible.
